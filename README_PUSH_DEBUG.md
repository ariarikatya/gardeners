# Инструкция по диагностике Push-уведомлений на iOS (Anemon Agro)

## Пошаговый чек-лист для проверки и сбора данных с устройства заказчика

### Шаг 1. Открытие приложения и проверка версии
1. Откройте приложение **Anemon Agro** обязательно с **иконки на Домашнем экране** iPhone (PWA/standalone режим).
   - *Важно:* Если на экране устройства несколько иконок Anemon Agro — удалите все старые и оставьте только последнюю созданную иконку.
2. Вверху в кабинете садовника возле кнопки «Уведомления» найдите строку самодиагностики.
3. **Сделайте скриншот** экрана с этой строкой. В ней видны 4 параметра:
   - `v1.0.0-YYYYMMDD` (версия клиенского бандела и кэша);
   - `mode` (`standalone` — приложение запущено с иконки, `browser` — вкладка Safari);
   - `perm` (`granted`, `denied`, `default`);
   - `sub` (`yes` — активна, `no` — отключена, `lost` — подписка на устройстве потеряна).

### Шаг 2. Настройка push-уведомлений
1. Нажмите кнопку **«Включить уведомления»** (или **«Восстановить подписку»**).
2. В системном всплывающем окне iOS выберите **«Разрешить»**.
3. Если после этого подписка успешно включилась — отобразится зелёная кнопка **«🔔 Уведомления вкл»** и придёт тестовое push-уведомление.
4. Если всплывает баннер/инструкция или предупреждение:
   - Не закрывайте окно, откройте в приложении адрес `/api/push/diagnose` или сохраните информацию с экрана;
   - Сообщите ваш **номер телефона** или **ID пользователя** разработчику.

### Шаг 3. Инструменты в UI (значок ℹ️)
При нажатии на значок **ℹ️** рядом с кнопкой уведомлений доступны 2 команды:
- **🔄 Перепроверить:** выполняет принудительную переподписку и синхронизацию с сервером.
- **🗑️ Сбросить кэш:** сбрасывает Service Worker и очищает устаревшие чанки браузера без потери авторизации.

## Диагностика со стороны разработчика / администратора

### 1. Проверка серверной диагностики `/api/push/diagnose`
Откройте `/api/push/diagnose` из браузере/WebApp. В ответе должны быть:
- `serverClientVersion`: совпадает с версией клиента;
- `swCacheName`: актуальное имя кэша (например, `anemon-agro-v1.0.0-20261008`);
- `mySubscriptionsCount`: количество подписок текущего пользователя;
- `clearCachesSnippet`: готовая команда сброса кэша для выполнения в консоли.

### 2. Просмотр серверной истории логов `/api/push/logs`
Запросите события подписи по ID пользователя:
```
GET /api/push/logs?userId=<USER_ID>&limit=100
```
В объекте `summary` вернётся готовый отчет:
- `lastClientVersion`: последняя версия клиенского кода, с которой приходил лог;
- `lastDisplayMode`: режим запуска (`standalone` / `browser`);
- `lastNotifPermission`: статус разрешений iOS;
- `iosGateShownRecently`: появлялся ли баннер «Добавьте на домашний экран»;
- `lastSubscribeError`: наименование и текст последней ошибки от `pushManager.subscribe()`.

Для выгрузки в текстовом формате используйте параметр `?format=text`.
